# Third-party material

Labyrinth Vault is MIT licensed (see [LICENSE](LICENSE)). Parts of it are
somebody else's work, and two of them are *copied* rather than depended on,
which is worth being explicit about: a fixed table you must reproduce exactly
is not a design decision anybody gets to make, and pretending otherwise would
be both a licensing problem and an interoperability one.

## Copied into this repository

**The Monero mnemonic word list** — `src/keys/monero-words.ts`

1626 words, transcribed verbatim from `src/mnemonics/english.h` in
[monero-project/monero](https://github.com/monero-project/monero), which is
BSD-3-Clause. Copyright (c) 2014-2024, The Monero Project.

It is copied rather than imported because a seed phrase written from a
different list restores to a different wallet. The list is the only reason a
phrase written down here can be typed into the official Monero wallet later.

**The bytewords table** — `src/airgap/bytewords.ts`

256 four-letter words from the Blockchain Commons **Uniform Resources** (BC-UR)
specification, taken from the reference implementation
[@ngraveio/bc-ur](https://github.com/ngraveio/bc-ur) (MIT) rather than retyped
from prose, and checked against its output in `test/bytewords.test.ts`.

Same reasoning: one wrong word means this device hands a different transaction
to a different wallet, and nobody finds out until the money is gone.

## Test vectors

- **BIP84** — the `abandon abandon ... about` account key and its first
  addresses, from the specification itself.
- **The Monero project's donation address**, published at
  [getmonero.org](https://www.getmonero.org/get-started/contributing/), used in
  `src/keys/monero.ts` as a known-good address that this code did not generate.
  It is a test vector and nothing else; this project has no connection to the
  Monero project.
- **BC-UR frames** in `test/fixtures/ur-vectors.json`, generated by running the
  reference implementation above.

## Dependencies

All MIT, all from the same two authors, all deliberately minimal:

| Package | What it does here |
|---|---|
| `@noble/curves` | ed25519 group arithmetic, for Monero keys |
| `@noble/hashes` | Keccak-256 and SHA-256 |
| `@scure/bip32` | BIP32 key derivation |
| `@scure/bip39` | BIP39 seed phrases |
| `@scure/btc-signer` | Bitcoin addresses, PSBT parsing and signing |

There is no dependency here that can open a socket, and
`test/no-network.test.ts` checks that the import list stays that way.
